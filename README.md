# JR Optimizer Pro

Aplicativo Windows para diagnóstico, limpeza, gerenciamento de inicialização,
desinstalação de aplicativos e perfis adaptativos de desempenho.

## Download

Baixe a versão mais recente na página **Releases** deste repositório.
Para a maioria das pessoas, use o pacote:

`JR-Optimizer-Pro-v2.2.0-Windows-x64-Portable.zip`

A versão portátil inclui o runtime necessário. Extraia o ZIP e execute
`JR Optimizer Pro.exe` como administrador.

## Compatibilidade

- Windows 10 ou Windows 11
- Processador de 64 bits
- Permissão de administrador para alterações do sistema
- Não exige Visual Studio
- A edição portátil não exige instalação separada do .NET

## Recursos

- Dashboard de CPU, RAM, disco e processos
- Limpeza leve e profunda
- Desinstalação em massa e revisão de resíduos
- Gerenciamento de programas na inicialização
- Perfis Dia a dia, Gamer, Multitarefa, Stream e Economia
- Configuração personalizada e reversível
- Monitor na bandeja do sistema
- Ferramentas de diagnóstico e reparo

## Segurança

O JR Optimizer preserva Windows Defender, Windows Update, Wi-Fi, áudio e
drivers. Crie um ponto de restauração antes de alterações avançadas.

Como o executável ainda não possui assinatura digital comercial, o Windows
SmartScreen pode mostrar um aviso na primeira execução.

## Aviso

Use por sua conta e risco. Revise as opções antes de aplicar ajustes avançados.
Algumas funções alteram configurações do Windows e exigem reinicialização.
